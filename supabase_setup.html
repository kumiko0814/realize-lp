— SUPABASE SETUP GUIDE —

Re:alize Quest ｜ Supabase 連携 設定手順

参加者全員のプロフィールをクラウドで共有する仕組み

STEP 01

🚀 Supabase アカウント＆プロジェクト作成

  1. supabase.com にアクセス
  2. 右上の Start your project をクリック
  3. GitHub でログイン（一番ラク）
  4. New Project をクリック
  5. 項目を入力：
    • Name: realize-quest
    • Database Password: 自動生成でOK（メモしておく）
    • Region: Northeast Asia (Tokyo)
    • Plan: Free
  6. Create new project をクリック → 1分待つ
★ Free プランで 無料、500MB DB、月50,000リクエストまで対応。Realize 20-100人なら余裕。
STEP 02

🗄 テーブル作成（SQL Editor で1回実行）

左メニューの SQL Editor → New Query をクリック。下のコードをコピペして Run。

CREATE TABLE realize_members ( id TEXT PRIMARY KEY, name TEXT NOT NULL, mbti TEXT, role TEXT, animal_key TEXT, ijouchi TEXT, strengths_others JSONB DEFAULT '[]'::jsonb, strengths_town2 JSONB DEFAULT '[]'::jsonb, strengths_additional JSONB DEFAULT '[]'::jsonb, my_strength_answer TEXT, current_goal TEXT, companion_level INTEGER DEFAULT 1, updated_at TIMESTAMPTZ DEFAULT NOW() ); -- 全員 SELECT 可能、自分の ID 行のみ INSERT/UPDATE 可能 ALTER TABLE realize_members ENABLE ROW LEVEL SECURITY; CREATE POLICY "everyone_can_select" ON realize_members FOR SELECT TO anon USING (true); CREATE POLICY "everyone_can_upsert" ON realize_members FOR INSERT TO anon WITH CHECK (true); CREATE POLICY "everyone_can_update" ON realize_members FOR UPDATE TO anon USING (true);
⚠ 上記の RLS（行レベルセキュリティ）は 「誰でも書き込めて、誰でも読める」状態。Realize の運用には十分。
もし不適切投稿をブロックしたい場合は、後で認証システムを追加できる。
STEP 03

🔑 URL と Anon Key を取得

左メニューの Settings → API をクリック。

2つの値をコピー：

  • Project URL：例 https://abcdefg.supabase.co
  • anon public key：長い JWT トークン（eyJhbGc... で始まる）
★ anon public key は 公開しても安全な設計（行レベルセキュリティで保護）。HTMLに直接書いてOK。
STEP 04

⚙ supabase_config.js に貼り付け

このプロジェクトの中の supabase_config.js ファイルを編集。

以下の2行を書き換える：

const SUPABASE_CONFIG = { url: 'https://abcdefg.supabase.co', ← Project URL anonKey: 'eyJhbGciOi...', ← anon public key get enabled(){ return !!(this.url && this.anonKey); } };

保存して git push（GitHub Pages を使ってる場合）。

STEP 05

✅ 動作確認

  1. quest_v2.html をブラウザで開く
  2. 街3クリアまで進める（早送り：MBTI診断 → 強み収集 → 街3でテキトーに回答）
  3. 異常値発見後、自動的に「☁ クラウドに登録中…」表示
  4. 街4に行く → メンバーズボードに「☁ クラウドから N人取得」表示
  5. Supabase ダッシュボードで Table Editor → realize_members を見ると、自分のデータが入ってる
★ 別ブラウザ（プライベートウィンドウ等）で別ユーザーキー ?u=test2&name=テスト で起動 → 街3クリアすると、最初のユーザーのメンバーズボードに新しい人が見える！
STEP 06

👥 実際の参加者への配布

20人の参加者に共有するもの：

  • 各参加者用URL：例
    https://kumiko0814.github.io/realize-lp/quest_v2.html?u=tanaka&name=田中
    （u= は参加者ID、name= は表示名）

くみこ側で distribute.html から個別URL一括生成できる仕組みも作成可能。

★ u（ID）が同じだと同じプロフィールとして上書きされる。
　20人それぞれにユニークなIDを割り当てる必要あり。

🎯 期待される効果

  • 「実在の仲間20人」がルミナリアに集結
  • 互いの異常値・強み・目標を 非同期で覗ける
  • 同じMBTI・同じ動物の仲間を発見できる
  • 「あの人もこんなことで悩んでたんだ」「この人の異常値、参考になる」
  • くみこは Supabase ダッシュボードで全員のデータを俯瞰できる
