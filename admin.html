📖 管理者ボードの使い方

— ADMIN MANUAL —

🎯 このボードでできること

  • 参加者ごとの専用URL発行（LINEで送る）
  • 20名以上の参加者の進捗をリアルタイム監視
  • 個別の参加者にメッセージ送信
  • 確認用と本番用のURL分離（テストデータを本番に混ぜない）

STEP 1：参加者にURLを送る（新規配布）

  1. 「① 個別URLジェネレーター」セクションへ
  2. URLモードを選択（生徒に送るなら「本番配布用」を必ず選ぶ）
  3. 参加者の英字ID（例：shimizu）と表示名（例：清水）を入力
  4. 「URL生成」ボタンを押す（必須！押さないとコピーできません）
  5. 「② LINE送付テンプレ」セクションの「テンプレをコピー」を押す
  6. LINE/メールで参加者に送る

STEP 2：参加者の進捗を見る

  1. 「📊 全メンバーの進捗」セクションに自動表示
  2. 各カードに動物・達成率・週数が見える
  3. カードをクリック → 詳細モーダル（OKR目標・強み一覧・異常値も見える）

STEP 3：メッセージを送る

  1. 上部の「あなたの管理者ID」で自分を選ぶ（くみこ／清水／講師A/B）
  2. 参加者カードをクリック → 詳細モーダル
  3. 下までスクロール → 「💌 ◯◯さんへメッセージ」欄
  4. 応援メッセージを書いて「📨 メッセージを送る」
  5. その参加者のダッシュボードに、あなたのアイコン付きで表示されます

⚠ よくあるトラブル

Q. URLをコピーしてもダメ／送ったら開けない

→ 「URL生成」ボタンを押し忘れていませんか？コピー前に必ず生成を押してください。
　 また、ID＋表示名の入力後に「URL生成」を再度押すと最新URLが反映されます。

Q. テスト中のデータと本番データを分けたい

→ URLモードで「確認用」を選択。自動で test_ prefix が付き、絞り込みで分離できます。

Q. メッセージを送ったのに参加者に届かない

→ 参加者のダッシュボード画面を再読み込み（Cmd+Shift+R）してもらってください。1分以内に自動更新されます。

📊 全メンバーの進捗 — 読み込み中 —

Supabaseに登録されている全参加者の進捗をリアルタイム表示。各カードをクリックで詳細表示。

① 個別URLジェネレーター

参加者の名前（英字推奨）を入力すると、その人だけの専用URLとLINE送付テンプレが出ます。

⚙ URL モード

★ 体験版URLは demo=1 付き。
　 卵を受け取るまでのみ体験可・目標入力もロックされます。

—
—

★ 「URL生成」ボタンを押した後にコピー or 動作確認できます。
　 入力を変えたら、もう一度「URL生成」を押してください。

⚠ 既存IDに注意：
過去にテストで使ったID（例：shimizu）を本番で再利用すると、前のデータが復元されます。
→ 「📊 全メンバーの進捗」セクションで既存IDを確認できます。リセットしたい場合は、該当カードを開いて「☠ クラウドデータを完全削除」を実行してください。

② LINE送付テンプレ（コピペでそのまま使える）

参加者個別LINEに、このまま送ってください。URLは上のIDで自動で埋まります。

参加者IDを入れると、ここにテンプレが出ます

③ 既存参加者リスト（3期メンバー）

既存OKRシートの参加者一覧。各人のIDからURLを生成済み。

④ お試し用URL（くみこ・翔ちゃん用）

テスト動作確認用。誰でも使えるサンプル。

くみこ（テスト）
u=kumiko-test
翔ちゃん（テスト）
u=sho-test
ゲスト（誰でも）
u=guest

テスト配布の進め方（推奨）

  1. まず 「④ お試し用URL」 で動作確認（くみこ＆翔ちゃんで触る）
  2. 気になる調整があれば、その場でフィードバック
  3. OKなら 「③ 既存参加者リスト」 から数人にテスト配布（5〜10名くらい）
  4. 1週間で「使いやすい？」「迷った？」を回収
  5. 反応見て、本配布 or 追加機能（グラフ／カウントダウン）開発の判断
